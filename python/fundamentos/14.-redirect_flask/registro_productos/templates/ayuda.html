¿Qué es una solicitud POST?

Es una solicitud que el navegador envía al servidor para enviar información, por ejemplo los datos de un formulario (nombre, precio, categoría). Los datos viajan dentro del cuerpo de la solicitud y en Flask se acceden con request.form.

¿Qué es una solicitud GET?

Es una solicitud que el navegador envía para obtener o pedir un recurso, como una página. No está pensada para enviar datos sensibles ni para modificar información en el servidor.

¿Para qué sirve redirect()?

Después de procesar un formulario con POST, redirect() le indica al navegador que realice una nueva solicitud, esta vez de tipo GET, hacia otra ruta. Esto evita que, si el usuario recarga la página, el navegador reenvíe el mismo formulario y se dupliquen registros, pedidos o cobros. Este patrón se conoce como POST → Redirect → GET (PRG).

¿Por qué request.form no está disponible después de la redirección?

Porque request.form pertenece únicamente a la solicitud POST original. Cuando se ejecuta redirect(), el navegador inicia una solicitud completamente nueva (una GET) hacia otra ruta, y esa nueva solicitud no incluye los datos del formulario. Por eso, si imprimimos request.form en la ruta de destino, aparece vacío: ImmutableMultiDict([]).
